# TAS movies

`manifest.toml` lists the published Super Metroid TASes used as verify inputs:
any%, low% and 100%, with download links and SHA-256 hashes. Download them
into this folder; movie files are gitignored.

Converting a movie to per-frame controller input is phase 1 of
[docs/PLAN.md](../docs/PLAN.md). The previous importer lives in `crates/movie`
in the tag `archive/pre-transpile-2026-10-17`.
