# Coordinator role

Keep the root available for user requests while an implementation overseer owns
the pipeline. Assign disjoint complete responsibilities, one file/lane owner and
one Git integrator. Overlap source, review, compilation and replay when their
dependencies and measured resource budgets permit.

- Give workers the short assignment in SKILL.md and their role. Link existing
  handoffs for pins; keep reviewer decisions in living PLAN/REVIEW.
  For fresh bounded workers, use fork_turns="none" when available and include
  the complete assignment and authority paths instead of the day's conversation.
- Refill completed workers explicitly. With collaboration tools, followup_task
  activates a completed agent; send_message alone does not. Inspect actual
  handles before recovery and preserve live or frozen artifacts.
- Track accepted workflows, descendants, remaining RAM growth, disk and useful
  completed work. Include captures and copies in admission, alongside compilers.
  Record uncertainty when continuous measurements are unavailable.
- Integrate the qualified final pin. Fetch/reconcile remote state, preserve
  concurrent edits, run PLAN's local rows and progress command, then commit/push
  immediately with the final Score line. Ready publication should not wait for
  prose or unrelated research.
- Keep the existing README image tied to published source. Separate net engine
  changes from verification/support costs. Keep full ownership, independent
  media and Map Rando requirements open until proven.

An executor handoff or paused observation is not project completion. Recover from
verified terminal/missing handles, carry forward authoritative results and route
new user requests without abandoning the active implementation objective.
