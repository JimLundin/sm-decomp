# Source role

1. Confirm the item is unclaimed with the coordinator and use the assigned base
   and file scope. Read applicable contracts.
2. Trace the complete responsibility: setup, update, callbacks, failure,
   reset/load, callers and retirement. Prefer existing owned modules and real
   shared behavior. Identify the actual state owner and remaining external writers.
   When moving fields or changing shared helpers, inventory actual compiled users
   and receiver types, including unconditional verification, host and native hooks.
   Carry accessor/borrow fixes with the change or release disjoint fixes to their
   owners; preserve one state owner and every existing crate/cfg reach.
   For authored display open/reset/checkpoint, preserve independently supplied
   final resident mutable state and immutable visible line history. Never rebuild
   final resident state from the last visible line: later HDMA/IRQ/vblank may change it.
   Validate required authored media/profile/state before adoption; keep one mutable
   owner and preserve lazy operational reads and failure prefixes.
   Record producer object IDs and authored visual/frame/part/material IDs at the original successful publication points; retain them through pending delivery/checkpoints/line history.
   Preserve lazy validation and partial failure prefixes; never infer those identities backwards from tile/OAM bytes or slots.
3. Preserve native/LE access, full and odd identities, captured versus fresh
   selectors, lazy reads, callback order and effects before failure. A safe entry
   must be safe through its callees for every input its interface permits;
   unchecked pointer creation still matters when the pointer is discarded.
   Derive byte-versus-element offset units from the actual operation. Rust
   assignment evaluates its RHS before the destination place; function arguments
   follow argument order. Preserve that order when introducing helpers.
4. Implement in the assigned checkout. Keep reachable unsafe backend capabilities
   explicit under PLAN's migration policy; completed owned modules forbid unsafe.
   Include adapters, callbacks and callers in the replacement cost. Report net
   production, legacy, unsafe and verification changes, explaining required growth
   and distinguishing substantive removal from formatting or relocation.
   Send the first coherent code pin and actual START/first-code UTC promptly,
   naming pending checks for publication under PLAN by the primary writer.
5. Format and freeze the final source. Deliver the existing patch/handoff and
   source pin, contract findings and named affected rows to the assigned reviewers
   and integrator. Label unobserved behavior accurately. Compilation and replay
   completion belong to their assigned executors unless you also own those roles.
   Format pruned snapshots directly with rustfmt using the project edition and skip_children=true; retain exact inputs/timing/results without copying verification/assets/caches just for module resolution.
   Retain executed nontrivial preservation guard code and its hash with the source
   receipt's input/output pins, invocation and result. Reuse verified helpers;
   handle Rust array type semicolons and proven rustfmt comma changes while
   preserving checks of semantics, callbacks and effect order.

Correct a rejected frozen candidate in a separate successor. Preserve the prior
artifact and explain the correction; transfer checks only where the source and
relevant dependencies remain unchanged.
