# Qualify replay

Read [PLAN](../../../docs/PLAN.md) first, then [REVIEW](../../../docs/REVIEW.md)'s
Milestone plan at each item's start. Phase 0 verification-loop work lands first;
its exit is two consecutive green scheduled full-corpus runs. REVIEW sets the
active phase; PLAN owns checks, resources, Git and completion. User instructions win.

Use the assigned item, owner, authoritative repository, checkout/base/source pin,
allowed files, affected rows, resource allowance and next recipient. A pruned
checkout still needs the authoritative repository path.

Use the root-admitted reader/capture allowance. For persistence changes read
[state migration](../../../docs/ENGINE_STATE_MIGRATION.md).

1. Accept only the released candidate and actual DLL/source/native identities.
   Preserve source, ROM, input, codec and loader guards. Read the relevant
   [movie commands](../../../movies/README.md) and PLAN's Fast loop.
2. Run assigned affected rows plus required smoke. Use existing segment data and
   the generic verifier. Partition independent work while preserving shared
   prefixes, full windows, expectations and capture provenance.
3. For required fresh captures, roundtrip or distribution checks, finish the
   actual dependency chain and verify restored bytes. Initialized machine
   persistence and prepared Session persistence are distinct.
4. Poll original handles. A quiet parent may own a hot child; inspect descendants
   before declaring a stall. An observation timeout is not terminal. Reuse
   confirmed results and preserve unobserved live jobs.
5. Deliver row/frame totals, failures, exact result/artifact identities and
   remaining coverage to the primary root. Release reader admission at termination.

Give already admitted failed-DLL/checkpoint narrowing an independent launch
scope when its inputs are pinned. Within that grant, start after predecessor
terminal release, exact guards and a fresh resource fit while fix/witness work
proceeds. A remaining wait names its missing input or admission.

A frame mismatch needs a regression row with its fix. Preserve comparisons and
expectations. Constructed checks follow REVIEW's no-movie exception. Mutation
runs occur at PLAN's bank-retirement point, with required full-corpus follow-up.

A changed layout identifier or wire format needs genuine initialized and required
starts/captures plus continuation. Preserve round-trip, extra-byte and input-prefix
rejections and actual source/native/ROM/full-input/loader proof. Matching persisted
layouts do not transfer behavior proof; use genuine bytes and never restamp a header.
Transfer accepted rows only for unchanged relevant pinned inputs. Record actual
START/EXIT when known, terminal/live handles and next recipient; replay completion
does not close unverified engine or ownership goals.
