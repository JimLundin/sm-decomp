# Triage labels

Record these role strings as `Triage:` in local ticket files. Work lifecycle
uses the separate `Status:` field described in `issue-tracker.md`.

| Canonical role | Local value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Specified and ready for an agent |
| ready-for-human | ready-for-human | Human implementation required |
| wontfix | wontfix | Will not be actioned |
