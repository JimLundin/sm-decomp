A practical order for rebuilding

  1. Make frame ownership explicit.Use separate Samus preparation and completion phases. Keep the existing interleaving and suspension points.
  2. Finish one gameplay responsibility.Move real callers, transitions, and state access together. Start from the named owners already present.
  3. Replace repeated algorithms.Share motion, timelines, or effect geometry only where order, arithmetic, and failure behavior agree. Count the complete replacement.
  4. Separate representation last.Keep byte-compatible state and the oracle during migration. A native renderer or new state format is a separate, measured replacement.
