# Prospective timed instruction patterns

`just pattern-prove ad` preserves an exact source snapshot and runs every pinned
native LDA absolute case plus eight literal independent boundary fixtures through
the actual timed emitter and fetch/PC operation. The source declaration records
AD as prospective, so normal generated tables leave it interpreted. The proof
does not advance acceptance.

AD declares all four native M/X combinations, binary and decimal flag states,
eight combined width/status conditions, A8 high-byte preservation, N/Z behavior,
program-fetch wrapping and wide data bank/24-bit wrapping. Its abstract corpus
checks complete CPU/sparse memory, ordered active bus accesses and exact cycles.
Emulation, decimal arithmetic, branch/index/direct-page penalties and control or
stack operations are explained exclusions. ADC remains blocked by known overflow
failures. Unimplemented future patterns require an explicit implementation and
independent validation decision.

Six AD-specific SNES tests use the prospective body. Literal hardware expectations
from the public Super Famicom timing rules cover ordered 6/8/12-clock mixed-speed
accesses, wide read bank crossings, RDNMI read effects, final-data-cycle IRQ/NMI
sampling, pending DMA and HDMA pauses, refresh, frame/input rollover, checkpoint
resumption and passive observations. These tests supplement existing independent
hardware oracles; running unrelated existing suites alone cannot prove AD.

`just pattern-promote SELECTION PROOF` requires an immutable measured selection
with no useful supported routine/width increment, positive observed AD execution
and a complete exact-source proof. It prepares the promotion before mutation,
preserving predecessor and source snapshots, then enables the declared pattern
with one observed address/MX key. Every other new CFG body is removed from the
actual table and retained as deferred inventory. The same emitter implementation
is shared by prospective and production execution.

Promotion then runs the existing cold acceptance command with timed-pattern
metadata. The promoted source reruns complete production corpus and independent
timing, candidate checks, focused instruction/bus comparison, all 18,000 clean
generated frames and applicable independent gates. Acceptance rechecks proof,
promotion declaration/emitter identities, real-ROM execution of the selected AD
key, every newly enabled/affected key and positive comparable instruction gain.
Source changes require a fresh proof; prospective reports cannot substitute for
production evidence. Failed or incomplete work keeps the prior accepted pointer
and preserves the candidate for normal diagnosis/pruning/retry.
